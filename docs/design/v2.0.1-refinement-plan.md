## Quality bars (enforced)

- Every change has a test, or an explicit “cannot run on this host / CI is the gate” note.
- `InvestigationBuilder.critique()` frozen triples stay frozen (`severity` / `message` / `path` for the original three rules).
- Investigation-time modules stay offline. Adapters continue to refuse `http:` / `https:`.
- Generator remains source of truth. No invented core OWL terms.
- Additive only: no breaking changes to the 2.0.0 public surfaces.
- Process-pool parallelism stays opt-in and off by default.
- Version metadata and docs must say **2.0.1** and distinguish 2.0.0 / 2.0.1 / 2.1 honestly.

## Deliberately left as 2.1

- Full C# / Java / Rust workflow **handlers** (Python-parity `hash_media`, adapters, partition scheduler).
- Rust `partition_by_roots` incoming closure (requires a host that can link `cargo test`).
- Remaining MCP-only `CRIT-H-*` rules (`AUTH-NON-INVESTIGATION`, `ACQ-INPUT-RESULT-INVERSION`, `RELATED-TO-OVERUSE`, `DICT-ENTRY-COLLISION`, `FACET-PROPS-ON-OBSERVABLE`, `PROXY-DUPLICATE`, `MARKING-INHERITANCE`, `CUSTODY-UNPAIRED`, `CONTEXTUAL-COMPILATION-OMISSION`, `ACTION-ROLE-CONTRADICTION`).
- Construction-finding adapter into `start_critic_review`.
- Live `ProcessPoolExecutor` (or C#/Java/Rust process-per-partition) as anything other than an explicit opt-in.
- Generating `ConditioningPhase` (and any other generate-lag type) into bindings. That is a generator run, not a 2.0.1 code change.
- SHACL quality when `case_validate` is absent. Skip remains `validator_unavailable`, never `conforms=True`.
- Network VICS / PhotoDNA / NCMEC clients.
